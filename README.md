# PedaForge — Functional POC

The working proof-of-concept of PedaForge, the AI teaching platform for the Busy Bees early-childhood network.

**Live:** https://anitateoyingying.github.io/pedaforge-poc/

- Sign in with Google or a demo account (login page → "Panel reviewer?")
- Data lives in Supabase Postgres (Singapore, `ap-southeast-1`) behind row-level security
- Roles: educators see their own work; directors review submitted layouts and see network activity

Modules: lesson planner, portfolio, work samples, AI coach, lesson observation, learning-needs analysis, PD dashboard, classroom layout planner with live safety rules, resource inventory, HQ control with layout approvals, and the Home Literacy suite (phonics, benchmark, reading coach with real speech recognition, draw & reflect, talking dictionary).

The grant-proposal site (four ECDA Innovation Sandbox proposals) lives separately at
https://github.com/anitateoyingying/pedaforge.
